# food-or-not-food-ML-classification-model-with-Hugging-Face
This project explores natural language processing (NLP) by fine-tuning a pre-trained DistilBERT model using the Hugging Face Transformers library. The model was trained to classify text descriptions as either food or not food, demonstrating the process of adapting a state-of-the-art language model to a custom binary classification task.



The project involved preparing and tokenizing text data, creating label mappings, training and evaluating the model, and deploying it through an inference pipeline for real-time predictions. Throughout development, model performance was analyzed and improved by debugging training and checkpoint-loading issues, reinforcing best practices in machine learning workflows.



Through this project, I gained hands-on experience with transformer architectures, transfer learning, model evaluation, checkpoint management, and the Hugging Face ecosystem. The final model successfully classifies unseen text descriptions and serves as an introduction to building custom NLP applications with modern deep learning tools.
